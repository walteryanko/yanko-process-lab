# Escopo da branch

A branch inclui código, configurações, testes, resumos e métricas tabulares. O ZIP completo contém os datasets NPZ e partículas. Execute `python scripts/bootstrap_demo.py` para reconstruir demonstrações ausentes no checkout; cálculos continuam locais. A demonstração de controle é a seed 4000, com resumo das 10 seeds. Verifique README e relatórios antes de interpretar os resultados.
